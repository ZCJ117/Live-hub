## 4. 本次收尾修复的缺陷

1. **订单卡片 createTime 丢失**：`QueryMyOrdersTool` 未解析 order-service 返回的时间字段 → 卡片缺"时间"要素（FR-05 卡片协议）。已补 ISO-8601 解析。
2. **m5_first_token 埋点失真**：原记录 `System.currentTimeMillis()`（墙钟时间戳），无法统计"首 token P90"（6.3 指标）。已改为本轮起点差值（ms）。

## 5. 遗留观察（不阻塞 MS1，转后续阶段）

1. `QueryMyOrdersTool` 存在未使用变量 `msg` 与 `objectMapper` 字段（既有代码，未动）。
2. 网关无 `/voucher-order/**` 路由：现有秒杀前端若走网关将 404；agent→order 为服务间 Feign 直连不受影响。属既有问题，建议单独评估（Phase 4 联调 T4.15 时处理）。
3. `common/RedissonConfig` host 读取 `spring.redis.host`（旧路径），agent-service 依赖默认值 localhost 兜底；多环境部署时需统一（T5 压测前处理）。
4. MS1 实机演示依赖：Docker 中间件（MySQL/Redis/Nacos）+ `GLM_API_KEY`，按演示脚本步骤 0~7 执行后，在本报告补记结果即可判定 MS1 门禁。
