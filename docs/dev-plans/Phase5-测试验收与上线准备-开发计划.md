## 1. 阶段目标

1. 交付 P1 功能：FR-12（会话评价）、FR-13（会话历史与工单进度查询），含会话回放快照与"基于此会话继续咨询"。
2. 完成埋点全量接入（PRD 6.2 全部 11 个事件，上报率 ≥ 99%）与 Grafana 双看板（业务 + 工程），漏斗与核心指标（6.3）可观测。
3. 完成 Gatling 压测并达到 4.1 节全部性能指标（含单实例 2C4G 并发 50 会话、错误率 < 1%）。
4. 完成灰度发布（10% → 50% → 100%，每档观察 ≥ 24h）与回滚演练，达成 MS4 退出标准（灰度期转人工率 ≤ 25%、P0 缺陷清零）。
5. 演示脚本与面试问答手册产出（求职作品集定位，第 7 章 MS4 交付内容）。
6. P2 客服工单工作台（FR-14）本阶段**仅完成发布冻结确认与启动排期**，不进入开发（R9 范围冻结）。

## 5. 验收标准（对齐 PRD 条目级验收标准）

**FR-12 验收标准（3.12）**
1. 评价提交成功率 100%；埋点上报率 ≥ 99%。
2. 每会话仅一次评价；用户忽略 24h 后不再提醒（用例验证）。

**FR-13 验收标准（3.13）**
3. 列表加载 P90 ≤ 1s。
4. 回放内容与实时会话一致率 100%（快照存储验证）。
5. 回放为静态快照不可继续对话；「基于此会话继续咨询」正确携带摘要。

**MS3 退出标准（第 7 章）**
6. 埋点上报率 ≥ 99%。
7. 压测达到 4.1 节全部指标（SSE 首 token P90 ≤ 1.5s、纯对话 P90 ≤ 5s、含工具 P90 ≤ 8s、工具 P95 ≤ 2s、并发 50 会话错误率 < 1%、历史读取 P90 ≤ 100ms）。

**MS4 退出标准（第 7 章）**
8. 灰度期间转人工率 ≤ 25%。
9. P0 缺陷清零。
10. 灰度三档（10%/50%/100%）每档观察 ≥ 24h 有日报记录。

**业务与体验目标复验（1.2，上线观察期口径）**
11. 一次解决率 ≥ 70%、转人工率 ≤ 20%（全量后 7 天日报趋势确认，未达标进入周迭代）。
