## 2. 环境准备中发现并修复的问题（真实缺陷，非虚构）

### 2.1 Phase 3 遗留：`sql/phase3-voucher-fields.sql` 从未应用
- 现象：VoucherParityTest JDBC 直查报 `Unknown column 'threshold'`（tb_voucher 缺 C2 字段）
- 处理：应用增量迁移（`threshold DECIMAL(10,2) NULL` + `applicable_scope VARCHAR(512) NULL`），SHOW COLUMNS 复验通过

### 2.2 RocketMQ 版本矩阵与 Boot 3.1 不兼容（3 层问题逐一定位）
| 组件 | 现象 | 根因 | 修复 |
| --- | --- | --- | --- |
| agent-service + rocketmq-spring 2.2.3 | 启动失败：`RocketMQTemplate` bean 缺失 | 2.2.3 的 RocketMQAutoConfiguration 在 Boot 3.1 不激活 | agent pom 显式 **2.3.0**（producer-only 路径不受 2.3.x 监听容器错位影响） |
| order/social + 2.3.0 | 监听容器 `NoClassDefFoundError: MessageModel`（5.x 类布局） | 2.3.0/2.3.1 打包错误：字节码按 client 5.x 编译、pom 却钉 client 4.9.4 | order/social pom：starter **2.3.1** + 直依赖 **rocketmq-client 5.3.1**（setNamespaceV2 需 5.2+）+ 排除 acl（其传递 common 4.9.4 与 client 5.x 冲突） |
| social 2.2.3 静默缺陷 | 消费者从未启动且**无任何报错** | 同 2.2.3 自动配置不激活，监听容器后置处理器未注册 | 与 order 同配方，重启后日志实证 `running container: DefaultRocketMQListenerContainer{consumerGroup='social-ticket-notify-group', topic='agent-m5-ticket-route'}` |
| broker 5.1.4 容器 | consumer 注册但不消费，每次 pull 报 `NoClassDefFoundError: StoreUtil`（estimateInMemByCommitOffset） | 5.1.4 broker 容器内 StoreUtil 静态初始化失败（pull 路径必经）；`useExperimentalRemoteShrinkMemTable=false` 无效 | 换 **4.9.4** broker/namesrv（remoting 协议与 4.9.4/5.3.1 客户端均兼容）→ 消费链路全通 |
| broker 注册地址 | producer `sendDefaultImpl call timeout` | brokerIP1=host.docker.internal 宿主机不可解析 | broker.conf `brokerIP1=127.0.0.1`（全客户端在宿主机，走端口映射） |
| Git Bash 挂载 | broker 读不到 broker.conf（`D:/Utils/Git/home/...`） | MSYS 路径改写容器内参数 | 容器内路径双斜杠 `//home//rocketmq//broker.conf` |

### 2.3 敏感词热更新时序缺陷（D-3 实现缺陷，联调发现）
- 现象：Nacos 发布新词表 → `EnvironmentChangeEvent` 触发、日志打印"已刷新"，但词表条数不变（读到的仍是旧值）
- 根因：`SensitiveWordService.onApplicationEvent` 与 `ConfigurationPropertiesRebinder` 监听同一事件且均无序——listener 先执行时 `AgentProperties` 尚未 rebind
- 修复：`SensitiveWordService.rebuild()` 改为**直接从 `ConfigurableEnvironment` Binder 绑定** `agent.security`（Nacos 属性源更新先于事件发布，任意监听顺序下均读到新值）；测试构造点同步适配（OutputFilterTest / SensitiveWordServiceTest / ReActEngineTest / ChatOrchestratorDispatchTest，MockEnvironment 注入）
- 回归：agent 套件 181 tests / 0 failures / 4 skipped
