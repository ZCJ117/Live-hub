# D1.8 埋点字段字典 v1

| 项 | 内容 |
|---|---|
| 版本 | v1.0（Phase 1 交付物，前端签核后冻结） |
| 依据 | PRD 6.2（11 个事件）、6.3 核心指标口径 |
| 事件命名 | `事件名 = 模块_对象_动作`（m5_ 前缀） |

## 1. 通用规范

- **通用属性**（全部事件必带，不逐事件重复列出）：

| 属性 | 类型 | 说明 |
|---|---|---|
| sessionId | string | 会话 ID |
| userId | string | 用户 ID |
| timestamp | long | **服务端时间**（毫秒），以前端上报的以服务端落库时间为准 |
| rulesVersion | string | 安全规则库版本（D1.5 §3.2，便于归因） |

- **上报通道（双通道）**：
  1. 前端事件 → `POST /agent/track`（统一上报接口，批量 ≤ 20 条/次，失败本地缓存重试）；
  2. 服务端关键事件（带 ★ 标记）由 agent-service 直接写库，**不依赖前端**（保证准确率，PRD 6.2 约定）。
- **存储**：写入 `agent_service.track_event` 轻量表（事件名/属性 JSON/服务端时间），按月分区，保留 180 天；Grafana 看板从该表聚合。
- **红线核对**：无设备指纹、无地理位置、无明文手机号（合规 §7.2，D1.5）。

## 2. 事件明细（PRD 6.2 全量 11 事件）

| # | 事件 | 触发时机 | 通道 | 事件属性（通用属性之外） |
|---|---|---|---|---|
| 1 | m5_session_start | SSE 建连成功 ★ | 服务端 | entry: my / order_detail / voucher_detail |
| 2 | m5_msg_send | 用户发送消息 | 前端 | msgLen: int；roundNo: int（会话内第几轮） |
| 3 | m5_first_token | 服务端发出首个 delta ★ | 服务端 | latencyMs: int（建连发起 → 首 delta）；降级标记: fallbackModel: bool |
| 4 | m5_tool_call | 每次工具调用结束 ★ | 服务端 | toolName; success: bool; latencyMs: int; stepNo: 1-8; errorCode? |
| 5 | m5_intent | 意图识别完成 ★ | 服务端 | intent: 7 类枚举; confidence: 0-1; clarifyRound: int; isFallbackMenu: bool（降级菜单时 true） |
| 6 | m5_refund_card_show | 退款确认卡片生成推送 ★ | 服务端 | orderId; taskId |
| 7 | m5_refund_confirm | 用户点击确认 ★ | 服务端 | taskId; result: PASS / FAIL; failReason?: OWNERSHIP / STATUS / IDEMPOTENT / EXPIRED |
| 8 | m5_ticket_create | 工单创建成功 ★ | 服务端 | ticketNo; category; priority; source: COMPLAINT / REFUND_REVIEW / TRANSFER_NO_SEAT / SYSTEM_FAIL |
| 9 | m5_transfer_human | 转人工触发 ★ | 服务端 | transferReason: HUMAN_DEMAND / TOOL_FAIL / CLARIFY_EXCEED / NEGATIVE_EMOTION |
| 10 | m5_session_end | 会话结束（主动/超时/转人工）★ | 服务端 | msgCount: int; durationMs: int; closeReason: USER / TIMEOUT / TRANSFER; resolvedInferred: bool（推断口径见 §4） |
| 11 | m5_rating_submit | 评价提交 ★ | 服务端 | score: 1-5（满意=4/5，映射规则 §4）; tags?: string[]（不满意时：NOT_SOLVED / IRRELEVANT / TOO_COMPLEX / OTHER） |

通道标注说明：★ 事件服务端直写（9 个）；m5_msg_send 为前端事件（活跃度统计，允许极端丢失）；m5_first_token 由服务端测量但前端需上报"建连发起时间戳"作为计算输入（属性 connStartTs 由前端事件附带，服务端据此计算 latencyMs）。

## 3. 前端配合事项（签核项）

| # | 事项 | 说明 |
|---|---|---|
| F-1 | 上报接口对接 | POST /agent/track，批量 + 失败重试；请求头携登录态 |
| F-2 | connStartTs 附带 | 建连请求带本地时间戳（仅用于首响计算输入，不参与持久化为"用户时间"） |
| F-3 | tool_call 状态条计时 | 前端以 tool_call/tool_result 事件渲染 FR-04 状态条，UI 反馈间隔 ≤100ms 属渲染侧验收（不入埋点） |
| F-4 | 评价标签字典 | 4 个 tag 的英文枚举与中文文案对齐本表 |

## 4. 指标计算口径（6.3 → 看板 SQL 约定）

| 指标 | 计算口径 |
|---|---|
| 一次解决率（北极星） | m5_session_end.resolvedInferred=true / 全部已结束会话；resolvedInferred = closeReason≠TRANSFER 且该 userId 24h 内无同 category 新会话（T+1 计算） |
| 转人工率 | m5_transfer_human 关联的 TRANSFERRED 会话 / 全部会话 |
| 意图识别准确率 | 抽样人工标注 vs m5_intent.intent 一致占比（周采样 100 条） |
| 工具调用成功率 | m5_tool_call.success=true / 全部 |
| 退款确认转化 | m5_refund_confirm(PASS) / m5_refund_card_show |
| 会话满意度 | m5_rating_submit.score ≥ 4 占比；score 映射：满意=4/5（前端二选一按钮映射），不满意=1 |
| 澄清轮次均值 | m5_intent.clarifyRound 均值（目标 ≤ 1.2） |
