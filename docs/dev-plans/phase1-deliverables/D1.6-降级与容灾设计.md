## 1. 降级场景总表（PRD 4.3 逐条落地）

### D-1 LLM 上游故障/超时

```
LLM 调用失败（超时/5xx/限流）
  → 重试 3 次，指数退避（200ms/800ms/3.2s，仅幂等的分类/摘要类调用重试；流式生成失败不重试直接降级）
  → 切换备用模型：GLM-5 ↔ glm-4-flash（双向）
  → 仍失败 → FAQ 直答：调 rag-service 检索 top1 原文（不生成）作为回答
  → rag 也不可用 → 固定话术："智能服务暂时不可用，已为您记录问题" + 自动建单（FR-09）+ 建单入口
```

- 故障判定：模型级熔断计数（滑动窗口，失败率 > 50% 持续 30s → 打开 60s），熔断期间直走备用模型。
- 会话状态不受影响；恢复后下一轮自动回主模型。
- **测试用例**：TC-DEG-01~03（见 D1.7 §4）。

### D-2 工具调用失败

```
单次工具失败（超时/异常）
  → Feign 层重试 1 次（仅幂等查询类；写操作不自动重试）
  → 仍失败 → Observation 告知 LLM"该工具不可用，请换路或告知用户"（LLM 换路：换参数/换工具/直接说明）
  → 同一会话连续 2 次工具失败 → 硬中断 ReAct 循环 → 转人工触发器（FR-10，transfer_reason=TOOL_FAIL）
```

- Feign 超时 2s（PRD 4.1 上限），connectTimeout 500ms。
- Sentinel 规则（Phase 2 引入 starter）：按 toolName 维度熔断（异常比例 > 50% / 慢调用比例 > 50% 持续 10s → 熔断 30s，半开探测），熔断期间工具直接返回快速失败 Observation，不占 8 步预算（计入失败计数）。
- 上游保护（R6）：agent 路由网关独立限流（D1.5 §2）+ 工具层并发信号量（单工具默认 20 并发，超限排队快速失败）。
- **测试用例**：TC-DEG-04~06。

### D-3 rag-service 故障

- 客服主链路（FR-01~06、08~11）**不依赖 RAG**：仅 FR-07 扩展信息（菜品/招牌）走 kb_search。
- rag 超时（内部直连 1.5s）/失败 → FR-07 降级：仅返回 query_shop 结构化字段 + "扩展资料暂不可用"；不重试、不计入工具失败计数（避免误触转人工）。
- **测试用例**：TC-DEG-07。

### D-4 依赖业务服务故障（order/voucher/shop）

- 复用 D-2 机制；叠加"主动建议建单或转人工"话术（FR-05 边界：仍失败 → 主动建议）。
- 降级期间卡片类响应禁止输出过期数据（无本地缓存兜底，宁可失败不可编造 —— R1 原则）。

## 2. 服务自身容灾

| 组件 | 策略 |
|---|---|
| MySQL | 复用主实例主从；agent-service 只读场景（回放）可走从库（Phase 5 视压测决定） |
| Redis 故障 | 短期记忆不可用时：当前轮降级为"无历史单轮应答" + 提示；建连依赖的频控计数失败 → 放行并告警（可用性优先于频控精度） |
| MQ 不可用 | 工单照常落库，notify_status=PENDING，恢复后补偿投递（D1.4 C5 幂等消费兜底） |
| SSE 线程池耗尽 | AbortPolicy → 429 语义友好提示（D1.2 §2.1），不崩溃不丢已建会话 |
| 30 分钟空闲关闭 | 调度任务每分钟扫描 agent_session（idx_status_close），置 CLOSED + 推 done 事件 |
| 服务重启 | 会话上下文在 Redis 持久，实例重启后同 sessionId 重连可恢复（FR-01 验收 3） |

## 3. 退款链路一致性（KD-7，最终一致 + 对账）

不引入 Seata。一致性保障三件套：

1. **顺序**：先 ADOPT agent_task（原子 UPDATE，唯一生效）→ 再写退款申请（order-service 落库）→ 再建复核工单；第二步失败 → task 状态回滚为 REJECTED（原因=系统失败）+ 用户提示重试，无资金动作。
2. **对账脚本**（每日）：`agent_task(ADOPTED, 昨日)` vs order-service 退款申请记录 全量核对，差异数即告警（R4 应对预案要求）。
3. **幂等**：actionId 一次性 + order-service 受理接口幂等键（task_id），重复提交无副作用。

## 5. 监控与告警口径

| 指标 | 告警阈值 | 动作 |
|---|---|---|
| SSE 建连成功率（5min 窗口） | < 99.5% | 页值班 + 检查线程池/网关 |
| 模型熔断打开次数（10min） | > 3 | 检查 LLM 上游配额/故障 |
| 工具成功率（10min 窗口） | < 99% | 检查对应业务服务 |
| 意图 JSON 解析失败率 | > 5%（R2 阈值） | 检查 prompt/模型行为 |
| 对账差异数（日） | > 0 | 立即人工介入（R4） |
| 单会话平均成本（日） | > ¥0.15（GLM-5 档上限） | 收紧分流/摘要策略（R5） |
