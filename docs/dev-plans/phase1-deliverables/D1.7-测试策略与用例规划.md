## 5. 测试环境与数据策略

- 环境：复用本地 Docker 中间件（Nacos/MySQL/Redis/RocketMQ/PgVector），CI 跑单元+集成层；LLM 调用在 CI 中用录制回放（WireMock 挂 OpenAI 协议 stub），真实 LLM 冒烟每日一次。
- 数据：对拍数据集用独立测试账号隔离生产语义；注入/越权用例使用专用测试用户，审计可辨识。
- 线上抽检（R1 长尾）：每日 20 条会话人工评审机制，Phase 5 T5.12 起常驻；抽检问题回流测试集。
