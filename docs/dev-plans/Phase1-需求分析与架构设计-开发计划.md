## 1. 阶段目标

1. 完成 PRD 开发评审：确认 P0/P1/P2 范围冻结，逐条确认附录 C 开发评审检查清单（7 项全部勾选）。
2. 完成 agent-service 技术架构设计：模块划分、SSE 异步链路方案、ReAct 编排设计、工具注册（ToolRegistry）机制、记忆机制、降级与熔断方案，产出《技术方案设计文档》并通过评审。
3. 完成数据模型详细设计：agent_session / agent_tool_call / agent_task / agent_ticket 四张表的字段级设计（含 PRD 6.1 补充字段：rating、transfer_reason、dedup_key）。
4. 确认外部依赖接口变更（附录 B，重点是 order-service 新增"按 userId 批量查询订单"接口与 rag-service 内部检索 API 暴露），推动后端评审通过并排期。
5. 明确测试策略与埋点字段字典（PRD 6.2 的 11 个事件与前端约定），为后续各阶段的自动化验收提供依据。

**范围声明**：本阶段为设计阶段，不编写任何业务代码；仅允许搭建空骨架工程结构与 CI 流水线配置（可选）。

## 3. 任务依赖关系

```
T1.1 PRD 评审/范围冻结
 ├─→ T1.2 架构设计 ─┬─→ T1.3 LLM 接入层设计
 │                  ├─→ T1.6 安全方案设计
 │                  ├─→ T1.7 降级方案设计
 │                  └─→ T1.11 工程骨架（可选）
 ├─→ T1.4 数据模型设计（依赖范围冻结的 P0 字段确认）
 ├─→ T1.5 外部依赖确认（并行启动，评审会前预沟通，会后正式确认）
 ├─→ T1.8 测试策略（依赖 T1.2 架构确定可测性切口）
 ├─→ T1.9 埋点字典（依赖 T1.1 冻结事件清单）
 └─→ T1.10 灰度回滚方案（依赖 T1.2 架构确定开关注入点）

关键路径：T1.1 → T1.2 → T1.5（order-service 接口确认是 Phase 2 的硬前置）
```

- T1.5 为**关键依赖**：order-service 新增接口未确认，Phase 2 的端到端工具调用无法开展，需在阶段出口前拿到书面确认。
- T1.8 的测试集建设可与后续阶段并行，但标注启动必须在阶段内完成。

## 5. 验收标准

1. PRD 评审完成，P0 范围（FR-01~FR-11）逐条确认无歧义，附录 C 检查清单 7 项全部勾选并有责任人签核。
2. 技术方案文档通过架构评审：SSE 异步方案、工具并行化方案、降级链路（4.3 全部 4 个场景）均有明确设计且评审通过。
3. 数据模型设计覆盖 PRD 6.1 全部 4 张表与 3 个补充字段，DDL 评审通过。
4. 附录 B 全部 6 项外部依赖确认完毕，其中 order-service 新增接口拿到后端书面确认与排期（Phase 2 硬前置）。
5. 埋点字典覆盖 PRD 6.2 全部 11 个事件，前端确认字段与上报方式。
6. 灰度开关与回滚方案（第 7 章）确认完毕。
7. 本阶段不产生任何业务代码（工程骨架初始化除外，且不含业务逻辑）。

## 6. 潜在风险与应对措施

| # | 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|---|
| P1-R1 | order-service 接口变更未及时评审通过，阻塞 Phase 2 端到端开发 | 中 | 高 | 评审会前预沟通；若阻塞，Phase 2 先用 Mock Feign 客户端开发工具层，接口就绪后切换真实调用 |
| P1-R2 | 范围蔓延：评审中引入新需求（如语音、站外渠道） | 高 | 中 | 以 PRD 1.5 非目标清单为硬边界，新增需求一律进 P2 备忘录，不进入 P0 范围（对齐 R9） |
| P1-R3 | SSE 异步链路技术方案争议（阻塞 vs 异步）导致评审拉长 | 中 | 中 | 以 PRD 4.1 性能设计约束为定论依据；提前做最小 Spike 验证（仅技术验证，不算业务代码） |
| P1-R4 | 测试集标注人力不足（意图 200 条/注入 30 条/多轮 50 组） | 中 | 中 | 采集与标注按周分批启动，P0 用例优先；可用 LLM 辅助生成初稿 + 人工复核 |
| P1-R5 | 合规要求理解偏差（AI 标识位置、数据保留期） | 低 | 高 | 对照 FR-11 与 4.2 逐条写入安全方案，发布 checklist 引用（R10） |
| P1-R6 | 埋点字典前后端理解不一致导致返工 | 中 | 低 | 字典双签制度；用具体请求/响应示例而非文字描述约定 |
