| 项 | 内容 |

## 1. 阶段目标

1. 交付 FR-03（意图识别与路由）：Planner 完成 7 类意图分类与分流，澄清/复合意图/上下文冲突三类边界全部实现。
2. 补齐查询类工具集，交付 FR-05（订单查询完整版）、FR-06（优惠券咨询）、FR-07（商户信息咨询）三条查询链路，达到条目级验收标准。
3. 完成 R1/R2 两大风险的架构性缓解落地：事实回答强制来源于工具返回、结构化输出稳定解析（JSON mode + schema 校验 + 重试）。
4. 意图识别准确率 ≥ 95%（200 条标注测试集）、查询链路对拍通过、端到端性能达标。

## 5. 验收标准（对齐 PRD 条目级验收标准）

**FR-03 验收标准（3.3）**
1. 意图分类准确率 ≥ 95%（标注测试集 200 条，覆盖口语化/错别字/方言表达）。
2. 澄清轮次均值 ≤ 1.2 轮（埋点统计）。
3. 超范围话题 100% 被引导回客服范围，无越界回答（安全测试用例 30 条全过）。

**FR-05 验收标准（3.5）**
4. 查询结果与数据库直查 100% 一致（自动化对拍 100 条）。
5. 越权查询 100% 被拦截，响应不泄露订单存在性。
6. 服务超时场景下用户 6s 内得到明确失败反馈与下一步指引。

**FR-06 验收标准（3.6）**
7. 券规则解释与数据库规则一致率 100%（对拍）。
8. 规则缺失场景 20 条用例中 0 次编造（人工评审）。
9. 端到端（含工具调用）P90 响应 ≤ 8s。

**FR-07 验收标准（3.7）**
10. 商户字段准确率 100%（对拍）。
11. 模糊店名场景 100% 走候选确认路径（测试 20 条）。
12. kb_search 扩展信息 100% 带来源标注。

**结构化输出稳定性（R2 对应）**
13. 意图 JSON 解析失败率 < 5%，失败场景 100% 降级为菜单选择。

|---|---|---|---|---|
