## 阶段间门禁

- Phase 1 → 2：order-service 新接口书面确认（硬前置）。
- Phase 2 → 3：MS1 退出标准（curl SSE 全链路 + 审计留痕）通过。
- Phase 3 → 4：意图准确率 ≥ 95%、对拍一致率 100% 通过。
- Phase 4 → 5：MS2 退出标准（P0 四类自动化用例 100% 通过）通过。
- Phase 5 内部：压测达标（MS3）→ 灰度发布（MS4），P0 缺陷清零 + 转人工率 ≤ 25% 方可全量。
