# HM-DianPing 仿大众点评系统

## 1. 项目简介

### 1.1 项目概述

HM-DianPing是一个基于微服务架构的仿大众点评系统，提供用户注册登录、商户信息展示、优惠券发放、订单管理、社交互动等核心功能。系统采用Spring Cloud Alibaba技术栈，实现了高可用、高性能、可扩展的微服务架构。

### 1.2 核心功能

- **用户服务**：用户注册、登录、个人信息管理
- **商户服务**：店铺信息展示、分类管理、店铺详情
- **优惠券服务**：优惠券发放、抢购、使用
- **订单服务**：订单创建、支付、查询
- **社交服务**：点赞、评论、关注
- **API网关**：统一入口、路由转发、权限控制

### 3.2 服务划分

| 服务名称          | 服务端口 | 主要功能                     | 核心数据模型               |
|-------------------|----------|------------------------------|----------------------------|
| gateway-service   | 8081     | API网关、路由转发、权限控制 | -                          |
| user-service      | 8082     | 用户注册、登录、个人信息管理 | User、UserInfo             |
| shop-service      | 8083     | 商户信息、店铺分类、店铺详情 | Shop、ShopType             |
| voucher-service   | 8084     | 优惠券发放、抢购、使用       | Voucher、SeckillVoucher    |
| order-service     | 8085     | 订单创建、支付、查询         | VoucherOrder               |
| social-service    | 8086     | 点赞、评论、关注             | Blog、BlogComments、Follow |

### 3.3 核心架构组件

1. **Nacos**：服务注册与发现、配置中心
2. **Spring Cloud Gateway**：API网关，统一入口
3. **OpenFeign**：服务间通信，基于HTTP的声明式客户端
4. **Seata**：分布式事务管理，保证数据一致性
5. **Redis + Redisson + Caffeine**：二级缓存、分布式锁
6. **Docker ：容器化部署
## 4. 快速开始

### 4.1 环境要求

- JDK 21+
- Maven 3.8+
- MySQL 8.0+
- Redis 6.0+
- Nacos 3.1.0+
- Seata 1.7.0+
- Docker 20.10+（可选，用于容器化部署）

### 4.2 环境搭建

#### 4.2.1 安装依赖服务
安装并启动以下依赖服务：
1. **MySQL**：创建数据库 `hm_dianping`，并执行项目提供的SQL脚本初始化表结构和数据，这个就在父工程目录下
2. **Redis**：启动Redis服务
3. **Nacos**：下载并启动Nacos服务，默认端口8848
4. **Seata**：下载并启动Seata服务，默认端口7091
5. **Docker**（可选）：安装Docker，用于容器化部署
6. **配置文件**：根据 `application-example.yml` 创建各个微服务的配置文件 `application.yml`，修改数据库、Nacos、Seata等配置信息
7. **端口配置**：确保各个微服务的端口不冲突

### 4.3.1 项目构建与启动 构建项目 

#### 4.3.2 启动服务

1. 启动顺序：
   - Nacos → Seata → Redis → MySQL
   - 然后启动各个微服务：User-Service → Shop-Service → Voucher-Service → Order-Service → Social-Service → Gateway-Service


### 4.4 访问系统

- API网关地址：http://localhost:8081
- Nacos控制台：http://localhost:8848/nacos
- Seata控制台：http://localhost:7091
