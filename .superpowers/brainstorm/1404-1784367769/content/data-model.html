PostgreSQL 数据库 · pgvector 扩展 · tsvector 全文索引

ER 关系

rag_knowledge_base (1) ──→ (N) rag_document (1) ──→ (N) rag_document_chunk
                                                   └─ vector(pgvector) + tsvector
rag_audit_log (独立，记录所有操作)

rag_knowledge_base — 知识库

按商户隔离，每个商户可创建多个知识库
列类型说明
idBIGSERIAL PK自增主键
merchant_idBIGINT NOT NULL商户 ID，权限隔离键
nameVARCHAR(100)知识库名称
descriptionVARCHAR(500)
chunk_sizeINT DEFAULT 500分块大小（字符）
chunk_overlapINT DEFAULT 50重叠大小
embedding_modelVARCHAR(100)默认 GLM Embedding
created_byBIGINT创建者用户 ID
created_at / updated_atTIMESTAMPTZ

rag_document — 文档

列类型说明
idBIGSERIAL PK
kb_idBIGINT FK所属知识库
filenameVARCHAR(255)原始文件名
file_typeVARCHAR(20)pdf/docx/xlsx/txt/md
file_sizeBIGINT字节数
file_pathVARCHAR(500)本地存储路径
statusVARCHAR(20)PROCESSING / COMPLETED / FAILED
chunk_countINT分块数量
error_msgTEXT失败原因
uploaded_byBIGINT
created_atTIMESTAMPTZ

rag_document_chunk — 分块（核心表）

列类型说明
idBIGSERIAL PK
document_idBIGINT FK
kb_idBIGINT FK冗余，加速按知识库检索
chunk_indexINT分块序号
contentTEXT分块文本
embeddingvector(1024)GLM Embedding 向量
tsvtsvector中文分词全文索引
metadataJSONB来源页码/行号等
created_atTIMESTAMPTZ

索引：IVFFlat 向量索引 (lists=100) · GIN tsvector 索引 · kb_id + document_id 联合索引

rag_audit_log — 审计日志

列类型说明
idBIGSERIAL PK
user_idBIGINT操作人
actionVARCHAR(50)UPLOAD / DELETE / QUERY / CREATE_KB
resource_typeVARCHAR(50)KB / DOCUMENT
resource_idBIGINT
detailJSONB操作详情（文件名、查询问题等）
ipVARCHAR(45)
created_atTIMESTAMPTZ
