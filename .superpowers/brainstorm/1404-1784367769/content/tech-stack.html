选型总览与理由

组件选择理由
向量数据库PgVector与 PostgreSQL 一体，向量+全文检索同一库，运维成本低；项目已有 MySQL，PG 仅用于向量场景
全文检索tsvector + zhparserPostgreSQL 原生，加中文分词插件即可，无需额外 ES 集群
混合检索RRF（倒数排名融合）简单有效，无需训练；k=60 参数可调，平衡向量和关键词贡献
LLMGLM-5兼容 OpenAI 协议，中文能力强，智谱 API 稳定性好
EmbeddingGLM Embedding (1024d)与 GLM-5 同生态，1024 维平衡精度与存储
文档解析Apache Tika 2.9Java 原生，自动格式检测，覆盖 PDF/Word/Excel/TXT/MD
异步消息RocketMQ项目已有，复用基础设施，下单模块已验证可靠性
HTTP 客户端OkHttp 4.12Spring Boot 默认，轻量高效，内置重试/超时
SSE 流式Spring WebFlux + Reactor原生支持 ServerSentEvent，非阻塞推送，网关需放行该路由
鉴权Sa-Token（复用现有）Redis 共享会话，网关统一校验，Controller 层取 UserHolder.getUserId()
API 文档SpringDoc OpenAPI 2.1Spring Boot 3 最佳实践，兼容 Swagger UI

Docker Compose 新增（仅 rag-service 需要的新组件）

在现有 docker-compose 中追加，下载路径 D:\Config\Docker
# PostgreSQL 16 + pgvector + zhparser（中文分词）
postgres-rag:
  image: pgvector/pgvector:pg16
  container_name: postgres-rag
  ports: ["5433:5432"]
  environment:
    POSTGRES_DB: rag_db
    POSTGRES_USER: rag_user
    POSTGRES_PASSWORD: ${RAG_DB_PASSWORD}
  volumes:
    - postgres_rag_data:/var/lib/postgresql/data
    - ./sql/init-rag.sql:/docker-entrypoint-initdb.d/init.sql

volumes:
  postgres_rag_data:

初始化 SQL：CREATE EXTENSION pgvector · 建表 · 建索引 · 配置 zhparser

应用配置（bootstrap.yml）

spring:
  application:
    name: rag-service       # 端口 8087
  cloud:
    nacos:
      server-addr: localhost:8848
      discovery.namespace: public
      config.namespace: public
      config.file-extension: yaml
  config:
    import: optional:nacos:${spring.application.name}.yaml

应用配置（application.yml）— 敏感信息走环境变量

server.port: 8087

spring:
  datasource:   # PostgreSQL (rag专用)
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://localhost:5433/rag_db
    username: ${RAG_DB_USER:rag_user}
    password: ${RAG_DB_PASSWORD}

glm:
  api-key: ${GLM_API_KEY}
  base-url: https://open.bigmodel.cn/api/paas/v4
  llm-model: glm-4-flash        # 可在 Nacos 覆盖
  embedding-model: embedding-2
  connect-timeout: 30s
  read-timeout: 120s
  max-retries: 3

rag:
  chunk:
    default-size: 500
    default-overlap: 50
  retrieval:
    default-top-k: 5
    max-top-k: 20
  conversation:
    max-history-turns: 10

rocketmq:
  name-server: 127.0.0.1:9876
  consumer:
    group: rag-doc-process-group
    topic: rag-document-process

Nacos 远程配置（rag-service.yaml）

用于存放可动态刷新的配置（@RefreshScope）：
· glm.llm-model — LLM 模型名可切换
· rag.chunk.default-size — 分块大小在线调整
· rag.retrieval.default-top-k — 检索数量
· 日志级别调整
· 不存敏感信息（API Key 仍在环境变量）
