REST API 接口设计

前缀 /api/rag · 统一返回 com.hmdp.dto.Result · Sa-Token 鉴权

1. 知识库管理

方法路径说明鉴权
POST/api/rag/knowledge-bases创建知识库商户管理员
GET/api/rag/knowledge-bases商户知识库列表登录用户
GET/api/rag/knowledge-bases/{id}知识库详情登录用户
PUT/api/rag/knowledge-bases/{id}更新配置商户管理员
DELETE/api/rag/knowledge-bases/{id}删除（级联文档+分块）商户管理员

2. 文档管理

方法路径说明鉴权
POST/api/rag/knowledge-bases/{kbId}/documents上传文档(multipart) → 返回 taskId商户管理员
GET/api/rag/knowledge-bases/{kbId}/documents文档列表（分页）登录用户
GET/api/rag/documents/{id}/status查询处理状态登录用户
DELETE/api/rag/documents/{id}删除文档+分块商户管理员

3. 问答（SSE 流式）

POST /api/rag/qa/chat — 核心接口，返回 SSE text/event-stream
// 请求体
{
  "kbId": 1,
  "question": "这家店的招牌菜是什么？",
  "messages": [                       // 多轮历史
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ],
  "topK": 5,                          // 检索数量
  "enableRerank": false               // 是否启用重排序
}

// SSE 响应流
data: {"type":"thinking","content":"正在检索..."}
data: {"type":"sources","chunks":[{...}]}
data: {"type":"delta","content":"这"}
data: {"type":"delta","content":"家"}
data: {"type":"delta","content":"店"}
...
data: {"type":"done"}

4. 审计日志

方法路径说明
GET/api/rag/audit-logs分页查询（支持按 user_id/kb_id/action 筛选）

SSE 多轮对话设计

客户端负责维护对话上下文，每次请求带上完整 messages 数组。
服务端取最后 N 轮（默认 10 轮）构建 Prompt，不持久化对话（简化设计）。
后续可按需加上对话持久化（Redis + MySQL），但当前版本先不做。
