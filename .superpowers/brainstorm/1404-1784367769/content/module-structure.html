关键设计决策

离线处理链路（异步）
POST /upload
→ 保存文件 + 建 Document 记录(status=PROCESSING)
→ 发 RocketMQ 消息
→ 立即返回 taskId

Consumer 消费：
Tika 解析 → 清洗 → 分块 → GLM Embedding
→ 写入 PgVector + tsvector
→ 更新 status=COMPLETED
→ 失败则 status=FAILED + 审计日志
在线问答链路（同步流式）
POST /qa/chat (SSE)
1. 加载商户知识库配置
2. HybridRetriever.retrieve()
   VectorRetriever (PgVector cosine)
   + KeywordRetriever (tsvector @@)
   → RRF 融合 Top-K
3. [可选] Reranker.rerank()
4. 构建 Prompt + 上下文
5. GlmLlmClient.streamChat()
6. SSE 逐 token 推送 + 最终返回引用来源
