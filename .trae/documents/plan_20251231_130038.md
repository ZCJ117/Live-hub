# Fix Gateway Service Issues

## 1. Fix Spring MVC vs WebFlux Conflict
**Root Cause**: The `gateway-service` depends on the `common` module, which includes `spring-boot-starter-web` (Spring MVC). However, `spring-cloud-starter-gateway` requires Spring WebFlux, and these two frameworks cannot coexist.

**Solution**: In `gateway-service/pom.xml`, exclude `spring-boot-starter-web` from the `common` module dependency to prevent Spring MVC from being included.

## 2. Fix Nacos Configuration Issue
**Root Cause**: The gateway-service is configured to read `gateway-service.yaml` from Nacos, but this file doesn't exist.

**Solution**: Create a proper `gateway-service.yaml` configuration file in Nacos with the necessary gateway configuration, or adjust the gateway-service to rely on local configuration files.

## 3. Fix Nacos Log Configuration Issue
**Root Cause**: Missing `nacos-logback.xml` configuration file for Nacos logging.

**Solution**: Create a basic `nacos-logback.xml` file in the resources directory to resolve the logging warning.

## Implementation Steps
1. Update `gateway-service/pom.xml` to exclude Spring MVC from the common dependency
2. Create or update the Nacos configuration for gateway-service
3. Create a basic nacos-logback.xml file
4. Test the gateway service to ensure all issues are resolved
