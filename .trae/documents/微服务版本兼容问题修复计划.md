# 微服务版本兼容问题修复计划

## 问题分析

错误：`java.lang.NoClassDefFoundError: org/springframework/web/client/RestClient$Builder`

原因：
- `RestClient.Builder`是Spring 6.1+才引入的类
- 当前使用的Spring Boot版本是3.1.12，对应的Spring版本是6.0.21
- Spring Cloud 2023.0.1版本中的`spring-cloud-commons`依赖了`RestClient.Builder`，导致版本不兼容

## 修复步骤

### 1. 降级Spring Cloud版本
将Spring Cloud版本从`2023.0.1`降级到与Spring Boot 3.1.12兼容的版本`2022.0.4`

### 2. 调整Spring Cloud Alibaba版本
确保Spring Cloud Alibaba版本与降级后的Spring Cloud版本兼容

### 3. 更新pom.xml配置
修改父pom.xml中的版本属性，确保所有依赖版本兼容

## 修复文件

- `d:\hm-dianping\pom.xml` - 更新Spring Cloud和Spring Cloud Alibaba版本

## 预期效果

修复后，所有微服务应该能够正常启动，不再出现类加载错误和版本兼容问题。
