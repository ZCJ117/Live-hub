# 大众点评项目版本升级计划

## 1. 准备工作

### 1.1 创建独立升级分支和备份
```bash
# 创建新分支
git checkout -b upgrade-java21-springboot3

# 备份当前代码
cp -r hm-dianping hm-dianping-backup
```

## 2. 升级Spring Boot和Java版本

### 2.1 修改pom.xml
- 将Spring Boot版本从`2.3.12.RELEASE`升级到最新稳定版`3.3.4`
- 将Java版本从`1.8`升级到`21`
- 更新maven-compiler-plugin配置

### 2.2 升级主要依赖版本
- MySQL Connector Java：从`5.1.47`升级到兼容Java 21的版本
- MyBatis-Plus：从`3.4.3`升级到兼容Spring Boot 3.x的版本
- Redisson：从`3.13.6`升级到兼容Spring Boot 3.x的版本
- Hutool：从`5.7.17`升级到兼容Java 21的版本

## 3. 处理javax到jakarta命名空间迁移

### 3.1 全局替换包名
- 将所有`javax.persistence.*`替换为`jakarta.persistence.*`
- 将所有`javax.servlet.*`替换为`jakarta.servlet.*`
- 将所有`javax.validation.*`替换为`jakarta.validation.*`
- 将所有`javax.annotation.*`替换为`jakarta.annotation.*`

### 3.2 检查相关注解和类
- 检查实体类（entity）中的JPA注解
- 检查控制器（controller）中的Servlet相关类和注解
- 检查服务层（service）中的相关注解

## 4. 升级各组件兼容性

### 4.1 数据库相关
- 升级MySQL驱动版本
- 检查MyBatis-Plus配置和API变化
- 检查数据源配置变化

### 4.2 Redis相关
- 检查Spring Data Redis 3.x的API变化
- 检查Redisson配置变化

### 4.3 RabbitMQ相关
- 检查Spring AMQP 3.x的配置和API变化

### 4.4 缓存相关
- 检查Spring Cache 3.x的配置变化

## 5. 检查和更新过时API

### 5.1 Java 8+ API变化
- 检查并更新工具类（utils）中使用的过时API
- 检查Lambda表达式、Stream API等在Java 21中的最佳实践

### 5.2 Spring Boot 3.x API变化
- 检查并更新Spring Boot 3.x中移除或更改的API
- 检查配置类的写法变化

## 6. 测试和验证

### 6.1 编译测试
```bash
mvn clean compile
```

### 6.2 单元测试
```bash
mvn test
```

### 6.3 启动测试
```bash
mvn spring-boot:run
```

## 7. 优化和调整

### 7.1 利用Java 21新特性
- 考虑使用虚拟线程（Virtual Threads）
- 考虑使用模式匹配（Pattern Matching）
- 考虑使用密封类（Sealed Classes）

### 7.2 利用Spring Boot 3.x新特性
- 考虑使用Spring Boot 3.x的新特性和优化

## 8. 合并分支

### 8.1 代码审查
- 对升级后的代码进行审查

### 8.2 合并分支
```bash
# 切换到主分支
git checkout main

# 合并升级分支
git merge upgrade-java21-springboot3
```

## 升级注意事项

1. 升级过程中要逐步进行，每完成一步就进行测试
2. 特别注意处理javax到jakarta的命名空间迁移，这是Spring Boot 3.x最重大的破坏性变更
3. 仔细检查每个依赖的兼容性，确保它们支持Java 21和Spring Boot 3.x
4. 测试过程中要覆盖所有主要功能，确保升级后项目能正常运行
5. 升级完成后，建议进行性能测试，确保升级后的项目性能符合预期
